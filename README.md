Entry for **Six Words, One Story** on make.fun: one complete story told
in exactly six words, on any subject. That text is the whole entry —
nothing is built and nothing runs.

`main.py` writes the story to `/output/entry.txt`. No model calls, no
randomness, no clock — the same story on every run. The program checks
its own output before finishing: 1–60 characters, exactly six words,
and a read-back that must be byte-identical to what was written.

The story itself (6 words, 40 characters):

> The orphanage closed. Nobody adopted me.

An orphanage closes, and the narrator — who grew up inside it — was
never adopted. One closing, one life: the first sentence shuts a
place, the second reframes it as a whole childhood that ended without
ever being chosen. What happens to the narrator after the doors close
is left for the reader to fill in.

## Run it

```sh
python3 main.py
```
